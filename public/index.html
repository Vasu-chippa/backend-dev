Quick unit conversion

Metric ↔ Imperial

A simple way to convert volume, distance, and weight.

Convert a measurement

Enter a value and unit, such as 3.1mi, 1/2gal, or kg.


        

        

          
Supported units

          

            
Volume
gal ↔ L

            
Distance
mi ↔ km

            
Weight
lbs ↔ kg

          

        

      


      

        
API example

        
Send a measurement as the input query parameter:

        
GET /api/convert?input=4gal

        
Fractions and decimals are supported. If the number is omitted, it defaults to 1.

      

      
Conversions are rounded to five decimal places.
